# KORA WALLET (Windows Desktop)

**Некастодіальний мультиланцюговий криптовалютний гаманець для Windows**

Версія: 3.5.0+1

---

## 📋 Огляд

**Kora Wallet для Windows** — це безпечний, некастодіальний криптовалютний гаманець, який підтримує декілька блокчейн-мереж. Створений на Flutter, він забезпечує нативний досвід Windows для управління цифровими активами через Bitcoin, Ethereum, Solana, Tron, BSC та інші основні блокчейни.

### Ключові можливості

- **Некастодіальний**: Повний контроль над вашими приватними ключами - зберігаються безпечно на вашому пристрої
- **Підтримка декількох ланцюгів**: 8+ блокчейн-мереж в одному гаманці
- **Мультиактивність**: Підтримка нативних монет та токенів (ERC-20, BEP-20, TRC-20, SPL)
- **HD гаманець**: Реалізація ієрархічно детермінованого гаманця BIP39/BIP32
- **Безпечне сховище**: Зашифровані приватні ключі через `flutter_secure_storage`
- **Ціни в реальному часі**: Живі ціни криптовалют через CoinGecko та CryptoCompare API
- **Історія транзакцій**: Повна історія транзакцій для всіх підтримуваних ланцюгів
- **Підтримка QR-кодів**: Генерація та сканування QR-кодів для адрес
- **Сучасний UI**: Красивий інтерфейс з підтримкою світлої/темної теми
- **Багатомовність**: Підтримка декількох мов

## 🏗️ Архітектура

### Технологічний стек

- **Фреймворк**: Flutter 3.10.4+ (Dart SDK)
- **Платформа**: Windows Desktop
- **Управління станом**: Riverpod (flutter_riverpod ^2.5.1)
- **Безпека**: 
  - `flutter_secure_storage` ^9.2.2 (зашифроване сховище ключів)
  - `encrypt` ^5.0.3 (AES шифрування)

  - `bip39` ^1.0.6 (генерація мнемоніки)

- **Мережа**:
  - `dio` ^5.4.3+1 (HTTP клієнт)
  - `web_socket_channel` ^2.4.5 (WebSocket для даних в реальному часі)
  - `http` ^1.2.1 (REST API виклики)

## 💰 Підтримувані блокчейни та активи

### Нативні блокчейни (8)

1. **Bitcoin (BTC)** - UTXO-базований блокчейн
2. **Litecoin (LTC)** - UTXO-базований блокчейн
3. **Bitcoin Cash (BCH)** - UTXO-базований блокчейн
4. **Ethereum (ETH)** - EVM-сумісна платформа смарт-контрактів
5. **Binance Smart Chain (BNB)** - EVM-сумісний (BSC)
6. **Ethereum Classic (ETC)** - EVM-сумісний
7. **Tron (TRX)** - DPoS блокчейн зі смарт-контрактами
8. **Solana (SOL)** - Високопродуктивний блокчейн

### Стандарти токенів

- **ERC-20** (Ethereum): USDT, USDC, DAI та кастомні токени
- **BEP-20** (BSC): USDT, USDC та кастомні токени
- **TRC-20** (Tron): USDT, USDC та кастомні токени
- **SPL** (Solana): USDC та інші SPL токени

### Загальна кількість підтримуваних активів

**17+ активів** включаючи:
- 8 нативних монет (BTC, ETH, SOL, BNB, TRX, LTC, BCH, ETC)
- 9+ токенів (USDT на декількох ланцюгах, USDC на декількох ланцюгах, DAI тощо)

## 🔐 Функції безпеки

### Управління ключами

- **BIP39 мнемоніка**: 12/24-словні фрази відновлення
- **BIP32 HD гаманець**: Ієрархічна детермінована деривація ключів
- **Безпечне сховище**: Зашифроване сховище через Windows Data Protection API
- **Без хмарного резервування**: Ключі зберігаються тільки на локальному пристрої

### Шифрування

- **AES-256 шифрування**: Військове шифрування для приватних ключів
- **Захист паролем**: Визначений користувачем пароль для доступу до гаманця
- **Безпечна пам'ять**: Чутливі дані очищаються з пам'яті після використання

### Автентифікація

- **PIN/Пароль**: Необхідний для транзакцій
- **Біометрична підтримка**: Інтеграція Windows Hello (опціонально)
- **Автоблокування**: Автоматичне блокування гаманця після неактивності

## 🔧 Технічна реалізація

### Блокчейн сервіси

#### Bitcoin/UTXO ланцюги (BTC, LTC, BCH)
```
lib/core/blockchain/bitcoin/
├── bitcoin_service.dart       # Отримання UTXO, баланс, broadcast
├── bitcoin_wallet.dart        # Генерація адрес (P2PKH, P2WPKH)
├── bitcoin_signer.dart        # Підпис транзакцій
└── bitcoin_transaction.dart   # Побудова транзакцій
```

**Можливості**:
- Підтримка адрес P2PKH (Legacy) та P2WPKH (SegWit)
- Вибір UTXO та побудова транзакцій
- Оцінка комісії через mempool.space API
- Трансляція транзакцій

#### Ethereum/EVM ланцюги (ETH, BNB, ETC)
```
lib/core/blockchain/ethereum/
├── ethereum_service.dart      # RPC виклики, баланс, транзакції
└── ethereum_wallet.dart       # Генерація адрес, підпис
```

**Можливості**:
- Підпис транзакцій EIP-155
- Підтримка токенів ERC-20
- Оцінка gas та розрахунок комісії
- Взаємодія з контрактами через web3dart
- Декілька RPC endpoints з fallback

#### Tron (TRX)
```
lib/core/blockchain/tron/
├── tron_service.dart          # Інтеграція TronGrid API
├── tron_wallet.dart           # Генерація адрес
└── tron_transaction.dart      # Побудова транзакцій
```

**Можливості**:
- Підтримка токенів TRC-20
- Управління Energy та Bandwidth
- Підпис транзакцій з Ed25519
- Інтеграція TronGrid API

#### Solana (SOL)
```
lib/core/blockchain/solana/
├── solana_service.dart        # RPC виклики, баланс
├── solana_wallet.dart         # Генерація адрес
└── spl_token.dart             # Утиліти SPL токенів
```

**Можливості**:
- Підтримка SPL токенів
- Схема підпису Ed25519
- Інтеграція Helius RPC
- Серіалізація транзакцій

### Потік виконання транзакцій

```
Користувач ініціює відправку
    ↓
SendScreen (валідація UI)
    ↓
Вибір відповідного executor на основі блокчейну
    ↓
[UTXO/EVM/Tron/Solana]Executor
    ↓
Побудова транзакції
    ↓
Підпис приватним ключем
    ↓
Трансляція в мережу
    ↓
Моніторинг підтвердження
    ↓
Оновлення балансу та історії
```

### Інтеграція API

#### Price APIs (з fallback)
1. **Основний**: CoinGecko API (безкоштовний рівень)
2. **Fallback**: CryptoCompare API
3. **Кеш**: Постійний локальний кеш

#### RPC Endpoints (з fallback)
- **Ethereum**: Ankr → PublicNode → LlamaRPC
- **BSC**: Binance dataseed1 → dataseed2 → dataseed3
- **Solana**: Helius → Public RPC
- **Bitcoin**: mempool.space → blockstream.info

#### Block Explorers
- **Ethereum**: Etherscan API
- **BSC**: BscScan / Blockscout
- **Bitcoin**: mempool.space / blockchain.info
- **Tron**: TronScan API
- **Solana**: Helius Enhanced Transactions

## 🚀 Функції

### Управління гаманцем

- **Створити новий гаманець**: Генерація нової 12/24-словної мнемоніки
- **Імпортувати гаманець**: Імпорт існуючого гаманця через мнемоніку
- **Декілька гаманців**: Підтримка декількох екземплярів гаманця
- **Резервне копіювання та відновлення**: Безпечне резервне копіювання мнемоніки

### Управління активами

- **Вигляд портфоліо**: Огляд всіх активів зі значеннями в USD
- **Ціни в реальному часі**: Оновлення цін через WebSocket
- **Зміна за 24 години**: Індикатори зміни ціни
- **Відстеження балансу**: Автоматичні оновлення балансу

### Відправка та отримання

- **Відправка транзакцій**: Відправка монет та токенів на будь-яку адресу
- **Вибір комісії**: Вибір між повільною/нормальною/швидкою комісією
- **Валідація адреси**: Перевірка адрес одержувачів
- **Сканування QR-коду**: Сканування QR-кодів для адрес
- **Генерація QR-коду**: Генерація QR-кодів для отримання

### Історія транзакцій

- **Повна історія**: Всі транзакції для кожного блокчейну
- **Деталі транзакції**: Перегляд повної інформації про транзакцію
- **Відстеження статусу**: Статус очікування/підтверджено
- **Посилання на block explorer**: Відкриття транзакцій в block explorers

### Налаштування та преференції

- **Тема**: Перемикання світлого/темного режиму
- **Мова**: Підтримка декількох мов
- **Безпека**: Налаштування PIN/пароля
- **Мережа**: Кастомні RPC endpoints (розширені)

## 🛠️ Збірка та запуск

### Передумови

- Flutter SDK 3.10.4 або вище
- Windows 10/11 (64-bit)
- Visual Studio 2019+ з C++ інструментами
- Git

### Налаштування

```bash
# Клонувати репозиторій
git clone <repository-url>
cd kora_windows

# Встановити залежності
flutter pub get

# Запустити в режимі debug
flutter run -d windows

# Збірка release
flutter build windows --release
```

### Скрипти збірки

Проект включає PowerShell скрипти для автоматизованих збірок:

```powershell
# Збірка release версії
.\build_release_all.ps1

# Збірка інсталятора (потрібен Inno Setup)
.\build_installer.bat
```

### Конфігурація

API ключі налаштовані в `lib/core/config/api_config.dart`:
- Etherscan API ключ (для історії транзакцій ETH)
- BscScan API ключ (для історії транзакцій BSC)
- Helius API ключ (для Solana RPC)
- CoinGecko API ключ (опціонально, для вищих лімітів)
