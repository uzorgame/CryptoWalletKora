# KORA MARKET

**Віджет для відстеження криптовалют у реальному часі для Windows**

Версія: 3.5.0+1

---

## 📋 Огляд

**Kora Market** — це легкий віджет для робочого столу Windows, який забезпечує відстеження цін на криптовалюти в реальному часі для топ-20 цифрових активів. Створений на Flutter, він пропонує елегантний, сучасний інтерфейс з оновленням цін через WebSocket потоки Binance.

### Ключові можливості

- **Оновлення цін у реальному часі**: Живі ціни криптовалют через Binance WebSocket API
- **Топ-20 активів**: Відстежуйте Bitcoin, Ethereum, Solana, BNB, Tron та 15+ інших основних криптовалют
- **Компактний дизайн**: Фіксоване вікно 820x420 оптимізоване для віджетів робочого столу
- **Світла/темна тема**: Автоматичне перемикання теми з плавними переходами
- **Мінімальне використання ресурсів**: Легкий Flutter додаток з ефективними WebSocket з'єднаннями
- **Завжди доступний**: Залишається поверх інших вікон для швидкої перевірки цін
- **Красивий UI**: Сучасний дизайн зі шрифтом SF Pro Display та плавними анімаціями

## 🏗️ Архітектура

### Технологічний стек

- **Фреймворк**: Flutter 3.10.4+ (Dart SDK)
- **Платформа**: Windows Desktop
- **UI компоненти**: Material Design з кастомними віджетами
- **Джерело даних**: Binance WebSocket API (потокова передача в реальному часі)
- **Управління станом**: Вбудоване управління станом Flutter з Listenable патернами
- **Управління вікном**: пакет `window_manager` для кастомних елементів керування
- **Графіки**: `fl_chart` для візуалізації цін
- **Іконки**: SVG іконки через `flutter_svg`

### Структура проекту

```
kora_windows/widget/
├── lib/
│   ├── main.dart              # Точка входу додатку та splash екран
│   ├── theme.dart             # Визначення тем (світла/темна)
│   ├── screens/
│   │   └── market_screen.dart # Головний екран відображення ринку
│   ├── services/
│   │   └── binance_service.dart # WebSocket з'єднання з Binance API
│   └── widgets/               # Багаторазові UI компоненти
├── assets/
│   ├── kora_logo.png          # Логотип додатку
│   ├── crypto_icons/          # SVG іконки для криптовалют
│   └── fonts/                 # Сімейство шрифтів SF Pro Display
├── windows/                   # Платформо-специфічний код для Windows
└── pubspec.yaml               # Залежності та конфігурація
```

### Основні компоненти

#### 1. **BinanceService** (`services/binance_service.dart`)
- Керує WebSocket з'єднанням з Binance API
- Підписується на потоки цін в реальному часі для 20+ торгових пар
- Обробляє життєвий цикл з'єднання (підключення, перепідключення, відключення)
- Парсить та транслює оновлення цін до UI

#### 2. **MarketScreen** (`screens/market_screen.dart`)
- Головний UI, що відображає список криптовалют
- Оновлення цін у реальному часі з відсотками зміни за 24 години
- Кольорове кодування рухів цін (зелений/червоний)
- Сортування за ціною, зміною або капіталізацією

#### 3. **ThemeNotifier** (`theme.dart`)
- Керує перемиканням світлої/темної теми
- Зберігає налаштування теми через SharedPreferences
- Забезпечує плавні анімації переходу теми

#### 4. **SplashScreen** (`main.dart`)
- Анімований splash екран з логотипом та індикаторами завантаження
- Плавний fade перехід до головного екрану ринку
- Відображає підтримувані криптовалюти в нижній смузі

### Конфігурація вікна

- **Розмір**: 820x420 пікселів (фіксований)
- **Title Bar**: Кастомний прихований title bar з кнопками мінімізації/закриття
- **Фон**: Прозорий з кастомним стилем
- **Позиція**: По центру екрану при запуску
- **Панель задач**: Видимий в панелі задач Windows

### Потік даних

```
Binance API (WebSocket)
    ↓
BinanceService (Менеджер з'єднань)
    ↓
Stream<PriceUpdate>
    ↓
MarketScreen (UI)
    ↓
Відображення користувачу (Ціни в реальному часі)
```

### Оптимізації продуктивності

- **Ефективний WebSocket**: Одне з'єднання для всіх потоків цін
- **Мінімальні перемальовування**: Оновлюються тільки змінені віджети цін
- **Кешування активів**: Локальні SVG іконки для миттєвого завантаження
- **Обмежені оновлення**: Оновлення цін обмежені для запобігання затримок UI

## 🚀 Збірка та запуск

### Передумови

- Flutter SDK 3.10.4 або вище
- Середовище розробки Windows 10/11
- Visual Studio 2019+ з інструментами розробки C++ для робочого столу

### Команди збірки

```bash
# Збірка для розробки
flutter run -d windows

# Release збірка
flutter build windows --release

# Збірка з кастомною назвою
flutter build windows --release --build-name=3.5.0 --build-number=1
```

### Встановлення

Віджет може бути розповсюджений як:
1. **Окремий EXE**: Розташований в `build/windows/runner/Release/`
2. **Пакет інсталятора**: Може бути упакований з Inno Setup або подібними інструментами

## 📊 Джерела даних

### Основний API: Binance WebSocket

- **Endpoint**: `wss://stream.binance.com:9443/ws`
- **Тип потоку**: Індивідуальні потоки тікерів символів
- **Частота оновлень**: Реальний час (оновлення менше секунди)
- **Формат даних**: JSON з ціною, об'ємом та зміною за 24 години

### Особливості API

- **Безкоштовний доступ**: API ключ не потрібен
- **Висока надійність**: 99.9%+ uptime
- **Низька затримка**: Пряме WebSocket з'єднання
- **Комплексні дані**: Ціна, об'єм, максимум/мінімум, відсоток зміни

## 🤝 Інтеграція з екосистемою KORA

Kora Market є частиною екосистеми криптовалют **KORA**:

- **Kora Wallet (Mobile)**: Некастодіальний мультиланцюговий гаманець для Android
- **Kora Wallet (Windows)**: Десктопна версія гаманця
- **Kora Market (Widget)**: Трекер цін у реальному часі (цей додаток)

Всі три додатки мають спільні:
- Єдину мову дизайну
- Типографіку SF Pro Display
- Узгоджені кольорові схеми
- Підтримку тих самих криптовалют
