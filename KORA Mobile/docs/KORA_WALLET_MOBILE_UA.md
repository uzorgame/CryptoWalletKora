# KORA WALLET (Mobile - Android)

**Некастодіальний мультиланцюговий криптовалютний гаманець для Android**

Версія: 3.5.0+24

---

## 📋 Огляд

**Kora Wallet для Android** — це безпечний, некастодіальний мобільний криптовалютний гаманець, який підтримує декілька блокчейн-мереж. Створений на Flutter, він забезпечує нативний Android досвід для управління цифровими активами через Bitcoin, Ethereum, Solana, Tron, BSC та інші основні блокчейни на ходу.

### Ключові можливості

- **Некастодіальний**: Повний контроль над вашими приватними ключами - ніколи не зберігаються на серверах
- **Підтримка декількох ланцюгів**: 8+ блокчейн-мереж в одному мобільному гаманці
- **Мультиактивність**: Підтримка нативних монет та токенів (ERC-20, BEP-20, TRC-20, SPL)
- **HD гаманець**: Реалізація ієрархічно детермінованого гаманця BIP39/BIP32
- **Біометрична безпека**: Підтримка відбитка пальця та розблокування обличчям
- **Secure Enclave**: Апаратне сховище ключів на підтримуваних пристроях
- **Ціни в реальному часі**: Живі ціни криптовалют з відстеженням зміни за 24 години
- **QR-сканер**: Вбудований сканер камери для адрес та платіжних запитів
- **Історія транзакцій**: Повна історія транзакцій для всіх підтримуваних ланцюгів
- **Відстеження портфоліо**: Вартість портфоліо в реальному часі з інтерактивними графіками
- **Сучасний UI**: Красивий Material Design інтерфейс з плавними анімаціями
- **Багатомовність**: Підтримка декількох мов
- **Кросплатформність**: Також доступний для iOS (майбутній реліз)

## 💰 Підтримувані блокчейни та активи

### Нативні блокчейни (8)

1. **Bitcoin (BTC)** - UTXO-базований блокчейн
   - P2PKH (Legacy) адреси
   - P2WPKH (SegWit) адреси
   - Оцінка комісії через mempool.space

2. **Litecoin (LTC)** - UTXO-базований блокчейн
   - Подібна до Bitcoin реалізація
   - Litecoin-специфічний формат адрес

3. **Bitcoin Cash (BCH)** - UTXO-базований блокчейн
   - Підтримка формату CashAddr
   - BCH-специфічна побудова транзакцій

4. **Ethereum (ETH)** - EVM-сумісна платформа смарт-контрактів
   - Підпис транзакцій EIP-155
   - Оцінка та оптимізація gas
   - Підтримка токенів ERC-20

5. **Binance Smart Chain (BNB)** - EVM-сумісний
   - BSC-специфічні RPC endpoints
   - Підтримка токенів BEP-20
   - Нижчі комісії gas ніж Ethereum

6. **Ethereum Classic (ETC)** - EVM-сумісний
   - Оригінальний Ethereum ланцюг
   - Підтримка EVM смарт-контрактів

7. **Tron (TRX)** - DPoS блокчейн
   - Підтримка токенів TRC-20
   - Управління Energy та Bandwidth
   - Швидка фінальність транзакцій

8. **Solana (SOL)** - Високопродуктивний блокчейн
   - Підтримка SPL токенів
   - Фінальність транзакцій менше секунди
   - Низькі комісії транзакцій

### Стандарти токенів

- **ERC-20** (Ethereum): USDT, USDC, DAI та 1000+ токенів
- **BEP-20** (BSC): USDT, USDC та BSC токени
- **TRC-20** (Tron): USDT, USDC та Tron токени
- **SPL** (Solana): USDC та інші SPL токени

### Загальна кількість підтримуваних активів

**17+ попередньо налаштованих активів** + можливість додавати кастомні токени:
- 8 нативних монет
- 9+ популярних токенів (USDT на 3 ланцюгах, USDC на 4 ланцюгах, DAI)
- Імпорт кастомних токенів через адресу контракту

## 🔐 Функції безпеки

### Багаторівнева безпека

#### 1. **Управління ключами**
- **BIP39 мнемоніка**: 12/24-словні фрази відновлення
- **BIP32 HD гаманець**: Ієрархічна детермінована деривація ключів
- **Безпечне сховище**: Android Keystore для апаратного шифрування
- **AES-256 шифрування**: Військове шифрування для приватних ключів
- **Без хмарного резервування**: Ключі ніколи не залишають пристрій

#### 2. **Автентифікація**
- **Захист PIN**: 4-6 цифровий PIN для доступу до гаманця
- **Біометрична автентифікація**: Відбиток пальця та розблокування обличчям
- **Автоблокування**: Налаштовуваний таймаут автоблокування (1-30 хвилин)
- **Блокування у фоні**: Негайне блокування коли додаток йде у фон

#### 3. **Безпека транзакцій**
- **Необхідне підтвердження**: PIN/біометричне підтвердження для всіх транзакцій
- **Валідація адреси**: Перевірка контрольної суми для всіх адрес
- **Підтвердження суми**: Чітке відображення суми відправки та комісій
- **Попередній перегляд транзакції**: Перегляд всіх деталей перед підписом

#### 4. **Конфіденційність**
- **Без аналітики**: Без відстеження користувачів або аналітики
- **Без облікового запису**: Без email, телефону або персональної інформації
- **Тільки локальні дані**: Всі дані зберігаються локально на пристрої
- **Готовність до Open Source**: Прозора реалізація безпеки

## 🔧 Технічна реалізація

### Блокчейн сервіси

#### Bitcoin/UTXO ланцюги (BTC, LTC, BCH)

**Реалізація**: `lib/core/blockchain/bitcoin/`

**Можливості**:
- Вибір UTXO з контролем монет
- Генерація адрес P2PKH та P2WPKH
- Побудова та підпис транзакцій
- Оцінка комісії (повільна/нормальна/швидка)
- Трансляція до декількох вузлів з fallback

**Використовувані API**:
- mempool.space (основний)
- blockstream.info (fallback)
- litecoinspace.org (LTC)
- api.haskoin.com (BCH)

#### Ethereum/EVM ланцюги (ETH, BNB, ETC)

**Реалізація**: `lib/core/blockchain/ethereum/`

**Можливості**:
- Підпис транзакцій EIP-155
- Трансфери токенів ERC-20
- Оцінка ціни gas
- Управління nonce
- Взаємодія з контрактами через web3dart

**Використовувані API**:
- Ankr RPC (основний)
- PublicNode (fallback)
- Etherscan API (історія транзакцій)
- BscScan API (історія BSC)

#### Tron (TRX)

**Реалізація**: `lib/core/blockchain/tron/`

**Можливості**:
- Підтримка токенів TRC-20
- Розрахунок Energy/bandwidth
- Підпис транзакцій з Ed25519
- Виклики смарт-контрактів

**Використовувані API**:
- api.trongrid.io (основний)
- TronScan API (історія транзакцій)

#### Solana (SOL)

**Реалізація**: `lib/core/blockchain/solana/`

**Можливості**:
- Підтримка SPL токенів
- Схема підпису Ed25519
- Серіалізація транзакцій
- Отримання recent blockhash

**Використовувані API**:
- Helius RPC (основний з API ключем)
- Public Solana RPC (fallback)

### Система оцінки комісій

Кожен блокчейн має виділені сервіси оцінки комісій:

```
lib/features/send/fee/
├── bitcoin_fee/
│   └── bitcoin_fee_service.dart      # mempool.space API
├── litecoin_fee/
│   └── litecoin_fee_service.dart     # litecoinspace.org API
├── bitcoin_cash_fee/
│   └── bitcoin_cash_fee_service.dart # BlockCypher API
├── ethereum_fee/
│   └── ethereum_fee_service.dart     # Etherscan gas oracle
├── bsc_fee/
│   └── bsc_fee_service.dart          # BscScan gas oracle
├── ethereum_classic_fee/
│   └── ethereum_classic_fee_service.dart # Фіксована комісія
├── tron_fee/
│   └── tron_fee_service.dart         # TronScan API
└── solana_fee/
    └── solana_fee_service.dart       # Helius RPC
```

**Рівні комісій**:
- **Повільна**: Низький пріоритет, довший час підтвердження
- **Нормальна**: Стандартний пріоритет, середній час підтвердження
- **Швидка**: Високий пріоритет, швидке підтвердження

### Оновлення цін у реальному часі

**Реалізація**: Binance WebSocket + REST API fallback

```
BinancePriceStream (WebSocket)
    ↓ (оновлення в реальному часі)
CryptoPriceService
    ↓ (fallback до REST)
CoinGecko API → CryptoCompare API → Кеш
    ↓
Розрахунок вартості портфоліо
    ↓
Оновлення UI через Riverpod
```

**Можливості**:
- Оновлення цін менше секунди через WebSocket
- Автоматичне перепідключення при втраті з'єднання
- Fallback до REST APIs якщо WebSocket не працює
- Постійний кеш для офлайн доступу
- Відстеження зміни ціни за 24 години

## 🚀 Функції

### Управління гаманцем

- **Створити новий гаманець**: Генерація безпечної 12/24-словної мнемоніки
- **Імпортувати гаманець**: Імпорт існуючого гаманця через мнемонічну фразу
- **Нагадування про резервне копіювання**: Постійні нагадування про резервне копіювання мнемоніки
- **Відновлення гаманця**: Відновлення гаманця з мнемоніки

### Управління портфоліо

- **Огляд портфоліо**: Загальна вартість в USD зі зміною за 24 години
- **Список активів**: Всі активи з балансами та вартостями
- **Інтерактивні графіки**: Графік вартості портфоліо за 7 днів
- **Сортування активів**: Сортування за вартістю, назвою або зміною за 24 години
- **Потягніть для оновлення**: Ручне оновлення балансу

### Відправка транзакцій

- **Мультиланцюгова відправка**: Відправка будь-якого підтримуваного активу
- **Введення адреси**: Ручне введення або сканування QR-коду
- **Введення суми**: Введення суми в крипто або USD
- **Вибір комісії**: Вибір швидкості транзакції та комісії
- **Адресна книга**: Збереження часто використовуваних адрес
- **Останні адреси**: Швидкий доступ до останніх одержувачів
- **Попередній перегляд транзакції**: Перегляд перед підтвердженням
- **Біометричне підтвердження**: Безпечне схвалення транзакції

## 🛠️ Збірка та запуск

### Передумови

- Flutter SDK 3.10.4 або вище
- Android Studio або VS Code
- Android SDK (API 21-34)
- JDK 11 або вище

### Налаштування

```bash
# Клонувати репозиторій
git clone <repository-url>
cd kora

# Встановити залежності
flutter pub get

# Запустити на підключеному пристрої/емуляторі
flutter run

# Збірка APK
flutter build apk --release

# Збірка App Bundle (для Play Store)
flutter build appbundle --release
```

### Конфігурація

1. **API ключі**: Налаштувати в `lib/core/config/api_config.dart`
   - Etherscan API ключ
   - BscScan API ключ
   - Helius API ключ (Solana)
   - CoinGecko API ключ (опціонально)

2. **Іконка додатку**: Розташована в `assets/app_icon.png`
   - Генерувати іконки: `flutter pub run flutter_launcher_icons`

3. **Середовище**: Створити `.env` файл з `.env.example`

### Тестування

```bash
# Запустити юніт тести
flutter test

# Запустити інтеграційні тести
flutter test integration_test/

# Запустити з покриттям
flutter test --coverage
```

## 🎨 UI/UX дизайн

### Система дизайну

- **Типографія**: Сімейство шрифтів SF Pro Display
- **Кольорова палітра**: 
  - Світла тема: Білий фон, сині акценти
  - Темна тема: Темний фон, сині акценти
- **Відступи**: Система сітки 8px
- **Радіус меж**: Послідовні заокруглені кути 12px-16px
- **Elevation**: Material elevation для глибини

### Потік екранів

```
Splash екран
    ↓
Онбординг (перший запуск)
    ↓
Налаштування гаманця (створити/імпортувати)
    ↓
Головний екран (портфоліо)
    ├─→ Деталі активу
    │   ├─→ Відправити
    │   └─→ Отримати
    ├─→ Історія транзакцій
    │   └─→ Деталі транзакції
    └─→ Налаштування
```

### Анімації

- **Splash**: Анімація fade-in та масштабування логотипу
- **Перемикання теми**: Плавна fade overlay анімація переходу
- **Елементи списку**: Ефект shimmer завантаження
- **Графіки**: Анімоване малювання ліній
- **Кнопки**: Ефекти масштабування та ripple
